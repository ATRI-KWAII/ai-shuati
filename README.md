# AI 刷题 · 学习通网课作业助手

一个通过脚本猫运行的学习通用户脚本。它使用用户配置的 OpenAI 兼容接口处理文字和图文题，并提供课程任务调度、视频与音频播放、章节切换及浮窗设置。

当前源码版本为 **v4.7.15**。入口文件是 `ai刷题.user.js`，保留了原脚本的作者标记。仓库中的脚本可直接安装，不需要构建。

## 安装与配置

1. 在 Edge 或 Chrome 中安装脚本猫。
2. 在 GitHub 打开 `ai刷题.user.js`，下载文件或复制完整源码。在脚本猫中导入文件，或新建脚本并粘贴源码。
3. 如果已经安装同名 AI 版，在原脚本编辑器里用新版源码替换并保存。保留 `@name` 与 `@namespace` 有助于沿用脚本身份和配置。其他会操作同一学习通页面的脚本应停用，以免重复播放、答题或切章。
4. 打开学习通。通过浮窗或脚本猫菜单进入 **AI 搜题设置**，填写接口信息。浮窗可用 **F9** 隐藏或恢复。
5. 刷新页面，从脚本猫菜单运行 **测试 AI 搜题接口**。使用图片题时再运行 **测试 AI 识图接口**。

| 配置 | DeepSeek 官方接口 | 其他 OpenAI 兼容接口 |
| --- | --- | --- |
| Base URL | `https://api.deepseek.com` | 服务商给出的基础地址，含必要的版本路径，例如 `https://example.com/v1` |
| 模型 | `deepseek-flash` | 服务商提供的模型 ID |
| API Key | 在脚本猫配置页填写 | 使用对应服务商的密钥，允许无鉴权的本地接口留空 |
| 发送题目图片给 AI | 需要处理图片题时勾选 | 需要模型支持 Chat Completions 的 `image_url` 输入 |

Base URL 也可以填写完整的 `/chat/completions` 地址。脚本会自动拼接缺失的接口后缀。新服务商域名可能需要脚本猫跨域授权，可按需添加对应的 `@connect`。DeepSeek 官方域名已在脚本中声明。 [DeepSeek 接口文档](https://api-docs.deepseek.com/api/create-chat-completion/) · [DeepSeek 图片输入](https://api-docs.deepseek.com/guides/vision/)

API Key 应保存在脚本猫的用户配置中。题干、选项和启用后读取到的图片会发往配置的 AI 服务。发布源码时保持 API Key、自动登录手机号和密码为空，避免提交脚本猫导出的配置、课程日志或浏览器数据。

## 使用行为

- **文字和图文题**：覆盖单选、多选、填空、判断和简答。脚本跳过已经检测为作答的题。模型答案仍需核对。
- **整卷预览考试**：支持 `/exam-ans/mooc2/exam/preview`，按页面上的 `.questionLi` 逐题读取并处理；跳过已作答和无法得到可靠答案的题。扫描结束后停留在当前页面，不自动交卷。原逐题考试页仍走 `missonExam`。
- **答题间隔**：浮窗输入秒数，范围 **0.5–60 秒**。点「保存」或按回车，下一次安排答题计时使用新值。这个间隔叠加在 AI 请求耗时之后。
- **测验提交**：普通自动提交默认关闭。启用后会检查答题状态，提交后等待页面确认。强制提交是独立开关，默认关闭。单独打开的作业页目前走填题流程。
- **课程任务**：依次处理本节附件。知识图谱、图片及不支持的任务会记入跳过计数，队列继续处理后续任务。队列结束后会尝试进入下一节，并识别学习通特定的「还有任务点未完成」跳转提示。
- **视频与音频**：使用原生播放器时读取实际播放进度和倍速。前台计时视频会走原生播放路径。短暂意外暂停可在页面可见时尝试恢复，视频弹题或验证出现时会等待。播放器可能限制可用倍速，浮窗会显示实际生效的值。
- **后台播放**：在「视频处理模式」里勾选「后台播放（原生播放器）」。这个开关默认关闭，启用后切换标签时会尝试让原生播放器续播。浏览器拒绝后台播放或后台长时间无进度时，脚本会等课程页重新可见后再试。
- **界面**：「隐藏学习通 AI 助手图标」默认关闭。开启后只隐藏匹配 `aihelper-small.png` 的官方图标，取消后恢复。

## 源码导航

入口文件按功能分段。维护时搜索函数名比依赖固定行号稳定。

| 模块 | 关键函数 | 修改时关注 |
| --- | --- | --- |
| 页面启动与路由 | `loadScriptSettings`、`matchRoute`、`handleKnowledgeCards`、`handleHomework`、`handleExam`、`handleExamPreview` | 顶层页面与章节 iframe 都可能运行脚本。新增路由时核对匹配范围、浮窗创建时机和异步回调是否属于当前页面。 |
| 任务队列 | `getTaskParams`、`missionStart`、`advanceTask`、`toNext` | `_mlist` 与 `_domList` 必须按相同索引增减。任务完成和跳过分别计数。异步回调使用 `isCurrentTask` 或 `scheduleOnPage` 避免旧章节回调影响新章节。 |
| 音视频 | `missionVideo`、`normalVideoPlay`、`findTaskMedia`、`updateMediaRate`、`forceCleanupAll` | 区分媒体节点、平台任务标记和面板状态。结束、切页或跳过时释放 Worker、请求、计时器及监听器。 |
| AI 请求 | `getAIConfig`、`getAnswer`、`requestAIAnswer`、`parseAIAnswer` | 请求使用非流式 Chat Completions，从 `choices[0].message.content` 取最终答案。缺失、截断或格式无效的结果会跳过，接口异常走调用方的错误处理。 |
| 图片输入 | `getQuestionImages`、`loadQuestionImage`、`requestQuestionImage`、`makeVisionContent` | 图片必须跟随所属题干或编号选项。优先读取懒加载属性，校验域名、大小和文件签名。针对学习通图片 CDN 传页面来源并校验最终跳转来源。 |
| 页面填题 | `startDoPhoneTimu`、`startDoWork`、`doHomeWork`、`missonExam`、`missionExamPreview`、`processExamPreview` | 移动测验、PC 测验、作业、逐题考试和整卷预览各有页面选择器。整卷预览从题干剔除题号操作区，选项按所在题容器读取，异步处理只作用于仍连接的当前页面。 |
| 编辑器与提交 | `getBlankInputCount`、`fillBlankAnswer`、`fillShortAnswer`、`finishQuiz` | 填空数量要与实际输入框对应。富文本写入经过 HTML 转义。点击提交和确认平台状态是两个阶段。 |
| 浮窗与偏好 | `showBox`、`loadScriptSettings`、`applyQuizSetting`、`setChaoxingHelperHidden` | 浏览器输入单位是秒，内部计时单位是毫秒。用 GM 储存同步 iframe 与标签页设置。 |
| 字体与依赖 | `decryptFont`、`decryptFontInIframe`、元数据 `@require` / `@resource` | 当前使用 jQuery、MD5、TyprMd5 和字符映射资源。移动元数据或替换依赖后同时检查字体解码和浏览器启动。 |

### AI 答案协议

`getAnswer(type, questionText, optionsData, elements)` 使用题型编号 **0–4**。模型回复 JSON 对象，解析器检查类型、数量和取值后再交给填题逻辑。

| 题型 | 模型返回示例 | 脚本使用的值 |
| --- | --- | --- |
| 单选 | `{"answer":[2]}` | 零基索引数组 `[1]` |
| 多选 | `{"answer":[1,3]}` | 零基索引数组 `[0,2]` |
| 填空 | `{"answer":["甲","乙"]}` | 按空顺序的字符串数组，长度必须等于空数 |
| 判断 | `{"answer":true}` | `对`，或由 `false` 得到 `错` |
| 简答 | `{"answer":"答案内容"}` | 纯文本字符串 |
| 无可靠答案 | `{"answer":null}` | 跳过本题 |

图文题的用户消息包含结构化题干、选项文本，以及按归属排列的 `image_url` 内容块。图片转换为 Base64 数据 URL。当前限制为每题 8 张、每张 2 MiB、合计 6 MiB。原始图片地址不作为图片内容发送。若图片读取失败，日志会提示原因并跳过，以免使用缺图的题干作答。

### 设置存储

| GM 键 | 用途 |
| --- | --- |
| `AI.baseURL`、`AI.model`、`AI.apiKey`、`AI.vision` | 接口与图片输入配置，由 `==UserConfig==` 定义 |
| `quiz.time` | 答题间隔，毫秒 |
| `quiz.sub`、`quiz.force`、`quiz.examTurn`、`quiz.goodStudent`、`quiz.alterTitle`、`quiz.review` | 测验、考试与页面偏好 |
| `videoMode`、`videoRate`、`showProgressBar` | 视频模式、设定倍速与进度条 |
| `backgroundPlay` | 原生播放器的后台续播开关 |
| `hideChaoxingHelper` | 官方 AI 图标显示开关 |

首次读取缺失的 `quiz.*` 设置时，会尝试旧的 `GPTJsSetting.*` 页面存储。新增键时宜提供默认值，并检查 iframe 订阅的设置变化是否会生效。

## 二次开发

1. **先定位模块。** 改接口时从 `requestAIAnswer` 入手。修具体页面时，从对应入口和 DOM 选择器入手。调度改动优先集中在 `advanceTask` 与 `toNext`。
2. **保留现有合同。** 选项编号、填空数组长度、完成与跳过计数、异步回调归属和跨域边界都会被下游依赖。
3. **按真实页面复测。** 在 DevTools 确认实际 DOM 和 iframe 归属。需要复现网络错误时，只保留状态码和可公开的域名，避免复制认证头、Cookie 或带签名的图片地址。
4. **更新版本与说明。** 每次发布同时更新 `@version` 和浮窗版本文字。把可见行为变化和已验证的路径记在 README 或提交说明中。

### 修改后验证

本仓库首版包含脚本和文档。使用 Node.js 做基本语法检查，再在脚本猫中验证依赖、存储、网络和 DOM 行为。

```bash
node --check ai刷题.user.js
```

| 场景 | 验证点 |
| --- | --- |
| 文字题和图片题 | 菜单的文字与识图测试通过。实际作业分别验证文字题、题干含图、选项含图，以及混合图文题。 |
| 整卷预览考试 | 确认识别题目总数、已作答题不重复点选、图片题进入识图、无可靠答案继续下一题，刷新后答案仍在；不得自动点击「交卷」。 |
| 图片下载失败 | 可定位到来源、HTTP 状态或格式问题。学习通 CDN 的同源跳转可完成，异常跳转和超限图片会停止当前题的请求。 |
| 答题间隔 | 例如保存 2 秒后刷新确认保留。再试 0.5 秒、60 秒和非法输入。 |
| 任务跳过与切章 | 跳过最后一个不支持的任务后能进入下一节。有确认弹窗时只操作目标弹窗的「下一节」。 |
| 播放与清理 | 对比设置倍速和播放器实际倍速。测试鼠标移出、手动暂停、开启后台播放后切换标签，以及离开章节后的资源清理。 |
| 提交确认 | 测验状态有回执才计为已提交。修改时可先用未开启自动提交的测试环境核对答题行为。 |

### 常见故障

| 表现 | 优先排查 |
| --- | --- |
| HTTP 401 / 403 | 确认密钥属于当前 Base URL，并检查模型访问权限。 |
| HTTP 404 | 核对模型 ID 和接口路径，检查是否误填了控制台网页地址。 |
| 无法连接 AI 接口 | 检查网络和脚本猫跨域权限。官方 DeepSeek 使用 `api.deepseek.com`，自定义服务需要其实际域名。 |
| 文字题正常、图文题被跳过 | 检查图片开关、视觉模型、图片读取日志和大小限制。若出现新的图片域名，先核实归属和重定向路径。 |
| 调大间隔仍在继续当前题 | 新值在下一次排程时读取，已经发出的 AI 请求和已安排的计时会按原流程结束。 |
| 高倍速回到 1× | 查看浮窗「当前实际速度」和原生播放器显示。课程播放器可能重设速度，任务完成状态由学习通确认。 |
| 整卷预览检测不到题目 | 核对路径是否为 `/exam-ans/mooc2/exam/preview`，以及 `.mark_table .whiteDiv .questionLi` 是否已经渲染；旧版只适配 `/exam/test/reVersionTestStartNew`。 |
